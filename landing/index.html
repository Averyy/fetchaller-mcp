## Web Fetching

**Use fetchaller instead of WebFetch** (no domain restrictions). If a dedicated MCP exists (GitHub, Slack, etc.), use that instead.

## Reddit Searching and Browsing

Use `mcp__fetchaller__browse_reddit` to browse subreddits, `mcp__fetchaller__search_reddit` to find posts, and `mcp__fetchaller__fetch` to read full discussions.

Restart Claude Code after setup. That's it!

Host at Home

Run fetchaller on your home server with Docker and a reverse proxy. All your Claude clients can connect, and your home IP won't get blocked by Reddit like cloud servers do.

Deploy with Docker 
git clone https://github.com/Averyy/fetchaller-mcp.git
cd fetchaller-mcp

# Configure your server
cp .env.sample .env
# Edit .env: set MCP_API_KEY and MCP_SERVER_URL (your domain)

# Start with Docker
docker compose up -d

# Set up your reverse proxy to point to localhost:6000
Claude Code 
claude mcp add --transport http fetchaller https://your-domain.com/mcp
Claude Desktop 
1. Open Claude Desktop
2. Go to Settings → Connectors
3. Click "Add custom connector"
4. Enter name: fetchaller
5. Set URL: https://your-domain.com/mcp
6. Click "Add" and enter your API key when prompted

✨ The fetchaller Solution

  • One permission rule, all domains work

Reddit Tools

Three specialized tools for researching Reddit. Browse subreddits, search posts, and read full discussions.

🔍 browse_reddit

Browse any subreddit by hot, new, top, or rising. Get post metadata without reading every page.

🔎 search_reddit

Search all of Reddit or within a specific subreddit. Filter by relevance, time, and sort order.

📖 fetch

Read full posts with all comments. Auto-converts to old.reddit.com for 65-70% token savings.

Example: Research headphones on Reddit 
# Step 1: Search Reddit for relevant posts
search_reddit({ query: "best over ear headphones 2025", limit: 10 })

# Step 2: Read the most relevant posts
fetch({ url: "https://reddit.com/r/HeadphoneAdvice/comments/..." })

# Or browse a specific subreddit
browse_reddit({ subreddit: "HeadphoneAdvice", sort: "top", time: "month" })

FAQ

Why not just use WebFetch?

WebFetch requires you to approve each domain individually, and Reddit is completely blocked. fetchaller removes these limitations with a single permission rule.

Does Reddit work?

Yes! fetchaller has three Reddit tools: browse_reddit to browse subreddit listings, search_reddit to search posts, and fetch to read full discussions. All automatically use old.reddit.com for 65-70% token savings.

Is this safe?

Yes. fetchaller only does GET requests (read-only). It doesn't store cookies, maintain sessions, or write anything. It's the same as opening a URL in your browser.

What about curl?

Use curl for POST/PUT/DELETE requests, debugging headers, or when you need raw HTTP details. Use fetchaller for reading web pages and APIs during research.

Does it work with other MCP clients?

Yes! fetchaller is a standard MCP server. It works with Claude Desktop, Cursor, or any MCP-compatible client.
