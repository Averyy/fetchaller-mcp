## Web Fetching & Search

**ALWAYS use fetchaller MCP tools instead of WebFetch and WebSearch.**
fetchaller has no domain restrictions, bypasses bot protection
(Cloudflare, Akamai, etc.), and produces much cleaner markdown
with site-specific content cleanup.

- **fetch** — Fetch any URL as clean markdown
- **search** — Web search (Google + DuckDuckGo combined)
- **browse_reddit** / **search_reddit** — Reddit listings and search
- **get_aliexpress_product** / **search_aliexpress** — AliExpress products
- **get_alibaba_product** / **search_alibaba** — Alibaba.com B2B products

Exception: If a dedicated MCP tool exists for a service
(e.g., GitHub via `gh` CLI), prefer that instead.

Restart Claude Code after setup. That's it.

Host at home

Run fetchaller on your home server with Docker and a reverse proxy. All your Claude clients can connect, and your home IP won't get blocked by Reddit like cloud servers do.

Deploy with Docker 
git clone https://github.com/Averyy/fetchaller-mcp.git
cd fetchaller-mcp

# Configure your server
cp .env.sample .env
# Edit .env: set MCP_API_KEY and MCP_SERVER_URL (your domain)

# Start with Docker
docker compose up -d

# Set up your reverse proxy to point to localhost:6000
Claude Code 
claude mcp add --transport http fetchaller https://your-domain.com/mcp
Claude Desktop
1. Open Claude Desktop
2. Go to Settings → Connectors
3. Click "Add custom connector"
4. Enter name: fetchaller
5. Set URL: https://your-domain.com/mcp
6. Click "Add" and enter your API key when prompted

What's included

Web search

Search Google and DuckDuckGo in parallel. Results are deduplicated, cached for 5 minutes, and returned as clean text. Search to find URLs, then fetch to read them.

Example: research a topic
# Step 1: Search the web
search({ query: "python asyncio best practices 2025" })

# Returns titles, URLs, and snippets from Google + DuckDuckGo
# Step 2: Read the most relevant results
fetch({ url: "https://realpython.com/async-io-python/" })

Reddit tools

Three specialized tools: browse_reddit for subreddit listings by hot/new/top/rising, search_reddit for searching posts across all of Reddit or within a subreddit, and fetch for reading full discussions with all comments. Auto-converts to old.reddit.com for 65–70% token savings.

Example: research headphones on Reddit
# Search Reddit for relevant posts
search_reddit({ query: "best over ear headphones 2025", limit: 10 })

# Read the most relevant posts
fetch({ url: "https://reddit.com/r/HeadphoneAdvice/comments/..." })

# Or browse a specific subreddit
browse_reddit({ subreddit: "HeadphoneAdvice", sort: "top", time: "month" })

FAQ

Why not just use WebFetch?

WebFetch requires you to approve each domain individually, Reddit is completely blocked, and there's no web search. fetchaller removes these limitations with a single permission rule and adds search, Reddit tools, and smart cleanup.

Can it search the web?

Yes. The search tool queries Google and DuckDuckGo in parallel. Results are deduplicated and cached. Use search to find URLs, then fetch to read them.

What sites are optimized?

GitHub, Stack Overflow (all SE sites), Hacker News, Medium (including custom domains), Hugging Face, Wikipedia, Reddit, and generic forums (XenForo, vBulletin, phpBB, Discourse). Each gets tailored cleanup saving 65–98% tokens. All other sites get universal junk removal.

Does Reddit work?

Yes. fetchaller has three Reddit tools: browse_reddit for subreddit listings, search_reddit for searching posts, and fetch for reading full discussions with all comments.

Is this safe?

Yes. fetchaller only does GET requests (read-only). It doesn't store cookies, maintain sessions, or write anything. It's the same as opening a URL in your browser.

What about curl?

Use curl for POST/PUT/DELETE requests, debugging headers, or when you need raw HTTP details. Use fetchaller for reading web pages and APIs during research.

Does it work with other MCP clients?

Yes. fetchaller is a standard MCP server. It works with Claude Desktop, Cursor, or any MCP-compatible client.
